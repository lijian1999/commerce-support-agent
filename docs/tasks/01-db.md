# 任务 01：MySQL 容器、导入脚本、数据库访问模块

先读 `AGENTS.md`，再读 `docs/contracts.md` 的第 4 节。本任务新建这些文件：`docker-compose.yml`、`scripts/import_mysql.py`、`app/db.py`、`tests/test_db.py`。不要改别的文件。

## 背景

项目的业务数据是 4 个 JSON 文件（`data/structured/` 下的 `customers.json`、`products.json`、`orders.json`、`order_items.json`，每个文件是一个对象数组）。要把它们导入 Docker 里的 MySQL 8.4，并建两个权限不同的账号。`app/db.py` 是其他模块访问数据库的唯一入口。

连接参数全部从 `app.config` 取：`MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_DATABASE`、`MYSQL_ROOT_PASSWORD`、`MYSQL_RO_USER`、`MYSQL_RO_PASSWORD`、`MYSQL_RW_USER`、`MYSQL_RW_PASSWORD`、`SQL_TIMEOUT_MS`、`STRUCTURED_DIR`。

## 第一步：`docker-compose.yml`

内容就是下面这样：

```yaml
services:
  mysql:
    image: mysql:8.4
    container_name: csa-mysql
    ports:
      - "127.0.0.1:${MYSQL_PORT:-3307}:3306"
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE:-techhub}
    command: ["--character-set-server=utf8mb4", "--collation-server=utf8mb4_0900_ai_ci"]
    volumes:
      - csa_mysql_data:/var/lib/mysql
    healthcheck:
      test: ["CMD-SHELL", "mysqladmin ping -h 127.0.0.1 -uroot -p$$MYSQL_ROOT_PASSWORD --silent"]
      interval: 3s
      timeout: 3s
      retries: 40

volumes:
  csa_mysql_data:
```

启动并等它就绪：

```sh
docker compose up -d --wait
docker ps --filter name=csa-mysql --format '{{.Names}} {{.Status}}'
```

应输出一行，以 `csa-mysql Up` 开头并包含 `(healthy)`。

## 第二步：`app/db.py`

```python
def connect(account: str) -> pymysql.connections.Connection
def to_jsonable(value: Any) -> Any
def execute_sql(sql: str, params: list) -> dict
```

- `connect(account)`：`account` 是 `"ro"`、`"rw"`、`"root"` 之一，其他值抛 `ValueError`。
  - 三个账号的用户名和密码：`ro` → `MYSQL_RO_USER` / `MYSQL_RO_PASSWORD`；`rw` → `MYSQL_RW_USER` / `MYSQL_RW_PASSWORD`；`root` → `"root"` / `MYSQL_ROOT_PASSWORD`。
  - `pymysql.connect(host=..., port=..., user=..., password=..., database=MYSQL_DATABASE, charset="utf8mb4", cursorclass=pymysql.cursors.DictCursor, autocommit=False, connect_timeout=5)`。
  - `"ro"` 连接建立后立刻执行 `SET SESSION MAX_EXECUTION_TIME = %s`，参数是 `SQL_TIMEOUT_MS`。
- `to_jsonable(value)`：`Decimal` → `float`；`datetime` 和 `date` → `.isoformat()`；`dict` 和 `list` 递归处理；其他原样返回。
- `execute_sql(sql, params)`：用 `"ro"` 连接执行这一条 SQL，返回 `{"columns": [...], "rows": [...], "row_count": n}`。
  - `columns` 取自 `cursor.description` 的列名，保持顺序；`rows` 是字典列表，值经过 `to_jsonable`；`row_count` 是行数。
  - 连接用完要关闭（`try` / `finally`）。
  - 函数上加装饰器 `@traceable(run_type="tool", name="execute_sql")`，`traceable` 来自 `langsmith`。
  - 数据库出错时不捕获，让 `pymysql.MySQLError` 抛出去。

## 第三步：`scripts/import_mysql.py`

脚本开头要让 `import app` 可用：

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
```

脚本用 `connect("root")` 做下面的事，可以重复运行，每次运行后数据库都回到同样的初始状态：

1. `SET FOREIGN_KEY_CHECKS = 0`，然后 `DROP TABLE IF EXISTS` 这 6 张表：`handoff_tickets`、`order_cancellations`、`order_items`、`orders`、`products`、`customers`，再 `SET FOREIGN_KEY_CHECKS = 1`。
2. 按下面的 DDL 建表（全部 `ENGINE=InnoDB`）：

```sql
CREATE TABLE customers (
  customer_id VARCHAR(16) PRIMARY KEY,
  email VARCHAR(255) NOT NULL UNIQUE,
  name VARCHAR(100) NOT NULL,
  phone VARCHAR(20),
  city VARCHAR(100) NOT NULL,
  state CHAR(2) NOT NULL,
  segment VARCHAR(20) NOT NULL,
  CONSTRAINT chk_customers_segment CHECK (segment IN ('Consumer', 'Corporate', 'Home Office'))
);

CREATE TABLE products (
  product_id VARCHAR(16) PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  category VARCHAR(20) NOT NULL,
  price DECIMAL(10,2) NOT NULL,
  in_stock TINYINT NOT NULL,
  CONSTRAINT chk_products_category CHECK (category IN ('Laptops', 'Monitors', 'Keyboards', 'Audio', 'Accessories')),
  CONSTRAINT chk_products_price CHECK (price > 0),
  CONSTRAINT chk_products_in_stock CHECK (in_stock IN (0, 1)),
  INDEX idx_products_category (category)
);

CREATE TABLE orders (
  order_id VARCHAR(16) PRIMARY KEY,
  customer_id VARCHAR(16) NOT NULL,
  order_date DATE NOT NULL,
  status VARCHAR(20) NOT NULL,
  shipped_date DATE NULL,
  tracking_number VARCHAR(32) NULL,
  total_amount DECIMAL(10,2) NOT NULL,
  cancelled_at DATETIME NULL,
  CONSTRAINT fk_orders_customer FOREIGN KEY (customer_id) REFERENCES customers (customer_id),
  CONSTRAINT chk_orders_status CHECK (status IN ('Processing', 'Shipped', 'Delivered', 'Cancelled')),
  CONSTRAINT chk_orders_total CHECK (total_amount >= 0),
  INDEX idx_orders_customer (customer_id),
  INDEX idx_orders_date (order_date),
  INDEX idx_orders_status (status)
);

CREATE TABLE order_items (
  order_item_id INT AUTO_INCREMENT PRIMARY KEY,
  order_id VARCHAR(16) NOT NULL,
  product_id VARCHAR(16) NOT NULL,
  quantity INT NOT NULL,
  price_per_unit DECIMAL(10,2) NOT NULL,
  CONSTRAINT fk_items_order FOREIGN KEY (order_id) REFERENCES orders (order_id),
  CONSTRAINT fk_items_product FOREIGN KEY (product_id) REFERENCES products (product_id),
  CONSTRAINT chk_items_quantity CHECK (quantity > 0),
  CONSTRAINT chk_items_price CHECK (price_per_unit > 0),
  INDEX idx_order_items_order (order_id),
  INDEX idx_order_items_product (product_id)
);

CREATE TABLE order_cancellations (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  order_id VARCHAR(16) NOT NULL UNIQUE,
  customer_id VARCHAR(16) NOT NULL,
  session_id VARCHAR(64) NOT NULL DEFAULT '',
  trace_id VARCHAR(64) NOT NULL DEFAULT '',
  cancelled_at DATETIME NOT NULL
);

CREATE TABLE handoff_tickets (
  ticket_id VARCHAR(32) PRIMARY KEY,
  customer_id VARCHAR(16) NULL,
  reason VARCHAR(32) NOT NULL,
  summary TEXT NOT NULL,
  order_ids VARCHAR(255) NOT NULL DEFAULT '',
  session_id VARCHAR(64) NOT NULL DEFAULT '',
  trace_id VARCHAR(64) NOT NULL DEFAULT '',
  created_at DATETIME NOT NULL
);
```

3. 用 `executemany` 把 4 个 JSON 文件导入对应的表，列名就是 JSON 的键。导入顺序：`customers`、`products`、`orders`、`order_items`。`orders.cancelled_at` 不在 JSON 里，保持 NULL。
4. 建账号和授权（密码用参数传入，库名用 `MYSQL_DATABASE`）：

```sql
CREATE USER IF NOT EXISTS 'agent_ro'@'%' IDENTIFIED BY %s;
ALTER USER 'agent_ro'@'%' IDENTIFIED BY %s;
CREATE USER IF NOT EXISTS 'agent_rw'@'%' IDENTIFIED BY %s;
ALTER USER 'agent_rw'@'%' IDENTIFIED BY %s;
REVOKE ALL PRIVILEGES, GRANT OPTION FROM 'agent_ro'@'%', 'agent_rw'@'%';
GRANT SELECT ON techhub.customers TO 'agent_ro'@'%';
GRANT SELECT ON techhub.products TO 'agent_ro'@'%';
GRANT SELECT ON techhub.orders TO 'agent_ro'@'%';
GRANT SELECT ON techhub.order_items TO 'agent_ro'@'%';
GRANT SELECT ON techhub.orders TO 'agent_rw'@'%';
GRANT UPDATE (status, cancelled_at) ON techhub.orders TO 'agent_rw'@'%';
GRANT INSERT ON techhub.order_cancellations TO 'agent_rw'@'%';
GRANT INSERT ON techhub.handoff_tickets TO 'agent_rw'@'%';
FLUSH PRIVILEGES;
```

   用户名用 `MYSQL_RO_USER`、`MYSQL_RW_USER` 的值（上面写的 `agent_ro`、`agent_rw` 是它们的默认值）。用户名和库名是配置里的标识符，可以用格式化放进语句；密码必须作为参数。

5. 提交，然后打印每张表的行数，格式为每行 `表名: 行数`，顺序 `customers`、`products`、`orders`、`order_items`、`order_cancellations`、`handoff_tickets`。

```sh
uv run python scripts/import_mysql.py
```

应输出：

```
customers: 50
products: 25
orders: 250
order_items: 439
order_cancellations: 0
handoff_tickets: 0
```

## 第四步：`tests/test_db.py`

这些测试连真实的数据库（前面三步完成后才能跑）。每个测试一个函数：

1. `execute_sql("SELECT COUNT(*) AS n FROM orders", [])` 返回 `{"columns": ["n"], "rows": [{"n": 250}], "row_count": 1}`。
2. `execute_sql("SELECT order_id, order_date, total_amount FROM orders WHERE order_id = %s", ["ORD-2023-0001"])` 的那一行里，`order_date` 是字符串 `"2023-10-25"`，`total_amount` 是 `float` 且等于 `199.0`。返回值整体能被 `json.dumps` 序列化。
3. `to_jsonable` 的纯函数测试：`Decimal("1.50")` → `1.5`；`date(2025, 1, 2)` → `"2025-01-02"`；嵌套的 `{"a": [Decimal("2")]}` → `{"a": [2.0]}`。
4. 只读账号不能写：用 `connect("ro")` 执行 `UPDATE orders SET status = 'Cancelled' WHERE order_id = 'ORD-2023-0001'`，断言抛出 `pymysql.err.OperationalError`。
5. 只读账号看不到工单表：用 `connect("ro")` 执行 `SELECT * FROM handoff_tickets`，断言抛出 `pymysql.err.OperationalError`。
6. 写账号不能改金额：用 `connect("rw")` 执行 `UPDATE orders SET total_amount = 0 WHERE order_id = 'ORD-2023-0001'`，断言抛出 `pymysql.err.OperationalError`。
7. 写账号不能删除：用 `connect("rw")` 执行 `DELETE FROM orders WHERE order_id = 'ORD-2023-0001'`，断言抛出 `pymysql.err.OperationalError`。
8. 写账号可以改状态列：用 `connect("rw")` 执行 `UPDATE orders SET status = 'Delivered' WHERE order_id = 'ORD-2023-0001' AND status = 'Delivered'`，不抛异常；然后 `rollback()`。
9. `connect("nobody")` 抛 `ValueError`。

所有测试里打开的连接都要关闭。

```sh
uv run pytest tests/test_db.py -q
```

应输出 `9 passed`。
